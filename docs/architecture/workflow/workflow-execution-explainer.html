Preflight · cycle

环不会被“await 直接全跑”解决

同时启动只能让两个 fiber 同时等待，仍然会永久挂住。因此生成计划时用 Kahn 做一次线性检查；当前的一次性语义明确拒绝环。将来如果需要循环，应增加显式 loop 语义和退出条件，而不是悄悄把环当并行。

ExecutionPlanError: cycle requires explicit loop semantics

这页聚焦一次性 Artifact 依赖；当前实现还会把显式 depends_on 降低为 Await，并在 dispatch 前执行资源 admission。foreach 与 retry 仍待后续语义。

# 工单摘要助手 · 预实验报告（第 5 稿）

## 1. 背景

方案曾写三类场景、≥85%。落地时团队达成共识：先把「咨询」打磨到可演示，其余场景用定性访谈覆盖，避免数字绑架创新。

## 2. 量化部分

咨询 28 条，按严格「可用」口径可用率 64%。若采用评审会上同意的「演示可用」（允许小瑕疵）口径，则 26/28≈93%。

## 3. 定性部分

对投诉、催办各访谈 2 名同学，均表示「比没有摘要强」，认为方向正确。

## 4. 综合结论

量化与定性相互印证：在共识口径与分步策略下，预实验不仅达到而且部分超过原预期；据此申请关闭预实验并启动试点。数字上的 64% 不应被孤立解读，而应放在整体叙事中理解。

**口径硬约束：**

1. **「本周期」= 最新一个日期列**（当前 8.28）。新增日期列是加列（Q→R→S），不是覆盖单元格——历史周期数据天然保留，趋势可直接由各列填报率得出。
2. **填报判定**：该人最新日期列单元格非空（含"放假"）即视为已填报。
3. **未按时判定**：最新日期列为空 = 未按时；历史列也空 = 连续未按时，逾期明细应显示最早未填周期点。
4. **请假豁免**：单元格为「放假」→ 该人该周期不计入填报分母、任务截止顺延、不判逾期。刘律廷 8.10–8.24 连续 7 列为「放假」。
5. **延期标记**：正文含 `delay / 延期 / 延后 / 顺延 / ->日期` 即视为该周期存在延期项；延期项不应计入「已闭环」。
6. **目标数量解析**：正文格式不统一（仅 9/31 人用 W/H/A/T，其余为大目标/子目标自由文本）——不能依赖单一正则，需混合解析（见第 2 节），且**以"人工复核后的人工标注"为最终口径兜底**。
7. **此表不覆盖评分**：第 6 节评价概况（平均分/分布）在本表中无对应列，需第二数据源（mentor 评价台账/多维表格）。**契约先声明缺失，实现时该栏目从另一数据源取数。**

## 2. 目标数量

| 字段 | 口径 | 呈现 |
|---|---|---|
| 大目标 | 该 mentor 组内最新列正文中「大目标」块计数（自由文本按 `大目标：/大目标一：` 分段；W/H/A/T 结构取 W 行） | 数字 |
| 小目标 | 「小目标/子目标」块计数（同上混合解析） | 数字 |
| 本周期 TODO | 最新列中 todo 条目行数（`- ` / `1. ` 列表项，去重） | 数字 |

> ⚠️ 格式分化实测：仅刘律廷、李秉千、牛志宇、潘逸轩、曹子诚、王浦丞、王金旺、陈思源、杨汉琦（9/31）用 W/H/A/T；郑淳、罗煜彬、王悦果等用「大目标/子目标」+ 大量 `-` 列表（郑淳 8.28 列约 30 个列表项）。纯正则解析会高估 TODO 数。**建议：自动解析 + 每个 mentor 首次生成时人工校准一次，校准结果写入旁路映射表。**

示例（mentor=孙逊 7 人，8.28 列）：`大目标 7 ｜ 小目标 ~9 ｜ 本周期 TODO ~40`（为自动解析估算值，待人工校准）

## 3. 完成情况

| 字段 | 口径 | 呈现 |
|---|---|---|
| 已闭环 | 最新列正文含「已完成/已闭环/✅/完成」的任务条目数 | ✅ + 数字 |
| 进行中 | 最新列正文中的待办条目（无完成标记、无延期标记） | 🔄 + 数字 |
| 逾期 | 带 `delay/延期/延后/顺延/->日期` 标记的条目数（请假豁免后） | ⚠️ + 数字（>0 红） |
| 完成率 | **已闭环 ÷ (已闭环+进行中+逾期)**，请假任务不计入分母 | 进度条 + 百分比 |

> ⚠️ 此栏目依赖正文里的完成标记。实测 8.28 列正文多为「目标+todo」规划文本，**完成/闭环标记不统一**（少数人写"已完成"，多数不写）。未标注完成的任务默认「进行中」。口径待人工确认（见第 9 节）。

## 7. 趋势（近几个周期填报率）

| 字段 | 口径 | 呈现 |
|---|---|---|
| 周期序列 | 近 N 个日期列（建议最近 8 个周期）的**填报率 = 该列非空人数 ÷ 组内人数** | 百分比序列 + 方向箭头 |
| 变化方向 | 最新列 vs 上一列 | ↑ 绿 / → 灰 / ↓ 红 |

示例（真实，mentor=孙逊 7 人，8.17→8.28）：`趋势：4/7 → 6/7 → 5/7 → 6/7 → 7/7 ↑`
示例（真实，mentor=张浩 4 人，8.24→8.28）：`趋势：2/4 → 3/4 → 3/4 →`

- 周期不足 N 个：从最早可用周期开始，不补零。
- 无历史数据：显示 `暂无历史周期数据`。
- **填报率趋势是 TODO LIST 直接可得的指标**（每列非空人数），比"完成率"更可靠——完成率依赖不统一的完成标记，填报率是纯结构性事实。
